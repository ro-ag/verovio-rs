# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc] as its
code of conduct.

Read the full text here:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Enforcement

To report an incident, open a private security advisory on
[GitHub][advisory] (it does not need to be a security issue — that's
just the most private channel the repo offers) or email the maintainer
listed in `Cargo.toml`.

Reports will be reviewed and responded to within a reasonable
timeframe. Confidentiality of the reporter is preserved.

[cc]: https://www.contributor-covenant.org/
[advisory]: https://github.com/ro-ag/verovio-rs/security/advisories/new
